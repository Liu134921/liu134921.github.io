# X_XGL_ 个人主页

我的个人主页与项目展示站点。这里放我正在做的东西、折腾过的实验，以及一些关于技术和生活的记录。

页面上的项目卡片会实时从 GitHub 同步，点击卡片即可在站内直接阅读该项目的 README，不必跳转。

## 站点内容

- **Hero**：头像、身份与一句自我介绍，快速了解我是谁。
- **个人项目**：从 GitHub 自动读取仓库，按最近更新排序，展示语言、Star、Fork 与许可证。
- **项目介绍**：点击项目卡片打开模态框，直接呈现仓库 README，支持标题、列表、代码块、表格与图片。
- **关于我**：方向、常用工具和当前状态。

## 设计特点

- 悬浮的液态玻璃导航：毛玻璃模糊、斜向高光与细微阴影，滚动时逐渐加深。
- 冰川青蓝主色，配合深浅两套主题，跟随系统偏好并记住选择。
- 卡片悬浮、内容滚动淡入等克制动效，并尊重系统的减弱动效设置。
- 响应式布局，桌面与移动端都保持一致的阅读体验。

## 技术栈

原生 HTML / CSS / JavaScript，无框架、无构建步骤；数据来自 GitHub REST API；托管于 GitHub Pages。标题字体使用 Space Grotesk，正文为 DM Sans。
